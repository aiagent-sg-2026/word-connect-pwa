# Word Connect PWA

Word Connect PWA is an original, family-safe swipe-word game for mobile and desktop. The product name is a working title.

Status: architecture/docs only — implementation 0%.

The goal is a mobile-first, installable, offline-first PWA with local progress and no backend required for MVP.

## Documentation

- [DESIGN.md](DESIGN.md) — architecture and decisions
- [SPEC.md](SPEC.md) — normative requirements and acceptance criteria
- [ROADMAP.md](ROADMAP.md) — phased implementation plan

## Recommended first milestone

**M1 = 20-Level Offline Vertical Slice.** It will prove the installable PWA, airplane-mode play, swipe/tap input, IndexedDB progress, coins/hints transaction, immutable hand-authored 20 levels, update waiting prompt, one migration fixture, and recovery shell. M1 is planned only; implementation does not begin in this bootstrap.
